# Moazzam Shoukat — Immigration & Education Consultancy Website

A modern, high-trust, conversion-focused multi-page immigration and test coaching platform built with **[Astro](https://astro.build)** and **[Tailwind CSS](https://tailwindcss.com)**, redesigned and inspired by the professional aesthetic of **[Via Nova Consultants](https://vianovaconsultants.com/)**.

---

## ✦ Design & Conversion Architecture (Via Nova Style)

- **Color Palette**: Deep Forest Green (`#064E3B`), Rich Emerald (`#059669`), Soft Mint (`#ECFDF5`), and crisp White/Slate surfaces for high trust and authority.
- **Header & Navigation**:
  - Top Bar with direct contact details (`+92-328-048-4399`, Lahore location, and email).
  - Main sticky navigation with **Countries dropdown** (Canada, Australia) and **Services dropdown** (all 7 dedicated services).
  - Prominent **“Book Free Consultation”** CTA button.
  - Minimalist **Sun / Moon icon-only theme toggle** (zero text, zero box borders).
- **Full-Width Hero Section**:
  - High-impact headline: **“IELTS, PTE & Immigration Expert”**.
  - Dual action CTAs: *“Book Free Consultation”* + *“WhatsApp Advisor (+92-328-048-4399)”*.
  - Verified trust indicators strip: 96% First-Attempt Pass Rate, 180+ Visas Granted, IELTS Band 8.5 Scorer, 98% NAATI Pass Rate.
- **Countries Section**: Dedicated side-by-side modules for **Canada** (Express Entry & PNP) and **Australia** (GSM Subclasses 189, 190, 491).
- **Floating WhatsApp Button**: High-conversion floating WhatsApp CTA button fixed to the bottom right (`+92-328-048-4399`) with pulse animation ring and hover tooltip.
- **100% Static & Blazing Fast**: Static Site Generation (SSG) producing instantaneous page transitions and optimal SEO indexing.
- **Mobile Responsive**: Fully responsive layout with animated hamburger drawer and touch-friendly menus.

## ✦ Which Files to Edit to Personalize Content & Results

### 1. Updating Student Results & Success Stories
Edit **[`src/data/successStoriesData.ts`](file:///C:/Users/G%20A%20GROUP/Documents/GitHub/moazzamshoukat/src/data/successStoriesData.ts)**:
- Add, update, or remove items in the `successStoriesData` array.
- Fields: `name`, `category` (`"IELTS"` | `"PTE"` | `"NAATI CCL"` | `"Canada PR"` | `"Australia PR"` | `"Student Visa"`), `title`, `achievement`, `targetBadge`, `date`, `city`, `scoreBreakdown`, `testimonial`, and `keyTakeaway`.
- Automatically populates the Home page teaser and the [`/success-stories`](file:///C:/Users/G%20A%20GROUP/Documents/GitHub/moazzamshoukat/src/pages/success-stories.astro) page with interactive category filtering.

### 2. Adding or Editing Blog Posts
Edit **[`src/data/blogData.ts`](file:///C:/Users/G%20A%20GROUP/Documents/GitHub/moazzamshoukat/src/data/blogData.ts)**:
- Contains the 8 SEO blog posts.
- Fields: `slug`, `title`, `metaTitle`, `metaDescription`, `category`, `publishDate`, `readTime`, `author`, `excerpt`, `keyTakeaways`, `sections`, and `conclusion`.
- Astro generates static HTML files (`/blog/<slug>/index.html`) automatically at build time.

### 3. Personalizing Service Pages (FAQs, Offerings, Statistics)
Each dedicated service page has its own isolated `faqs`, `offerings`, and `stats` array at the top of the file:
